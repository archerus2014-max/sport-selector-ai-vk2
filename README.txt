SPORT SELECTOR AI — готовая версия VK-бота

1. Скопируйте vk_bot.py и engine.py в папку проекта.
2. Создайте папку data (бот создаст её сам при запуске).
3. В .env укажите:
   VK_TOKEN=ваш_токен_сообщества
   VK_GROUP_ID=154840474
4. Активируйте .venv.
5. Выполните:
   pip install -r requirements.txt
6. Запустите:
   python vk_bot.py

ВАЖНО:
- Бот читает событие MESSAGE_NEW через VkBotLongPoll.
- Ответы сохраняются в data/users.json.
- Возраст проверяется ДО расчёта рекомендации.
- Для ребёнка 5 лет ни один из 9 перечисленных видов не будет показан как спортивная подготовка по ФССП, если min_age выше 5.
- Это не запрет на физкультурные/развивающие занятия вне программы спортивной подготовки.

ПРОВЕРКА:
Напишите боту СТАРТ.
Для возраста 5 лет после теста бот должен сообщить, что по возрастным границам ФССП из этих видов нет подходящего вида спортивной подготовки.
Для возраста 7 лет в список допуска попадут только виды с min_age <= 7.
