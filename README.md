# Спорт-Подбор AI — реальный VK MVP

Это готовый MVP VK-ассистента для первичного подбора вида спорта ребёнку.

## Стек
- Python 3.11+
- FastAPI
- VK Callback API
- OpenAI Responses API
- httpx
- алгоритмический scoring engine
- in-memory session storage

## Запуск
1. Установить Python 3.11+.
2. `python -m venv .venv`
3. Windows: `.venv\\Scripts\\activate`
4. `pip install -r requirements.txt`
5. Скопировать `.env.example` -> `.env`.
6. Заполнить `VK_TOKEN`, `VK_CONFIRMATION_CODE`, при необходимости `VK_SECRET`, `OPENAI_API_KEY`.
7. `uvicorn app.main:app --host 0.0.0.0 --port 8000`
8. Проверить `/health`.
9. Опубликовать сервер по HTTPS (Cloudflare Tunnel/ngrok/хостинг).
10. В VK -> Управление сообществом -> Работа с API -> Callback API создать сервер и указать `https://ВАШ-ДОМЕН/vk/callback`.
11. Включить событие `message_new`.
12. Написать сообществу `спорт`.

## AI
AI используется для объяснения результатов и последующего свободного диалога. Сам рейтинг считает детерминированный scoring engine, чтобы модель не могла произвольно назначить ребёнку спорт.

## Безопасность
Не вводите в чат медицинские диагнозы. Бот не диагностирует и не определяет медицинскую пригодность. При ограничениях или неизвестности бот останавливает подбор и рекомендует обратиться к врачу и тренеру.

## Научная база
Общие принципы построены с учетом рекомендаций WHO по физической активности детей 5–17 лет и принципов безопасного, возрастно- и индивидуально-ориентированного вовлечения в физическую активность.
